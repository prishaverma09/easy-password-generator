# Simple Java Password Generator

A lightweight, terminal-executable password generation tool built in Java for secure, customizable credential creation.

## System Requirements

- Java Development Kit (JDK) 8 or higher installed on your system.
- A command-line terminal (Command Prompt, PowerShell, Terminal, or bash).
